# Mission Control - Assessment Delivery System

## Overview

Mission Control is the assessment delivery interface for administering the 9 assessment types generated by the Bank Creator system. This MVP starts with Letter Recognition (LR-ALPH) and will expand to all assessment types.

## Architecture

### Backend (Flask)
- Session management
- Response recording
- Real-time scoring
- Data export

### Frontend (Vanilla JS)
- Assessor dashboard with controls
- Student view (stimulus display)
- Timer and navigation
- Click cycle state management

## Quick Start

### 1. Start Backend
```bash
cd mission_control/backend
python3 app.py
```

Backend runs on http://localhost:5002

### 2. Open Frontend
```bash
open frontend/assessor_view.html
```

Or serve via Python:
```bash
cd mission_control/frontend
python3 -m http.server 8080
```

Then open: http://localhost:8080/assessor_view.html

## Usage

1. **Start Assessment**
   - Select assessment form
   - Enter student information
   - Click "Start Assessment"

2. **Administer Assessment**
   - Student sees stimulus (letter) on left screen
   - Assessor uses click cycle buttons to mark responses
   - Timer counts up automatically
   - Use navigation to move between items

3. **Complete Assessment**
   - Click "Stop & Score" when finished
   - View results (accuracy, time elapsed)
   - Results exported to JSON in `database/sessions/`

## API Endpoints

- `POST /assessment/start` - Initialize session
- `GET /assessment/<session_id>/item/<index>` - Get item
- `POST /assessment/<session_id>/record` - Record response
- `POST /assessment/<session_id>/timer/start` - Start timer
- `POST /assessment/<session_id>/timer/stop` - Stop timer
- `POST /assessment/<session_id>/complete` - Complete and score
